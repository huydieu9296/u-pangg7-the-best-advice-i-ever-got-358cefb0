One sentence, no longer than 200 characters, about the best advice I ever received — for the [make.fun bounty](https://make.fun/bounty/u-pangg7-the-best-advice-i-ever-got-358cefb0).

## The entry

> My grandmother, her hands white with flour, told me never to trust anyone who is only kind when they need something.

116 characters, one sentence. A real moment — my grandmother at the kitchen table, mid-baking — and advice that has held up far beyond it: kindness that only appears when something is wanted is not kindness, it is a transaction. Plain, specific, and earned the hard way.

## How it runs

`main.ts` (Node 22, no dependencies, no network) reads the sentence from `entry.txt` next to it, checks the gate locally (1–200 characters, not only whitespace), and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
node main.ts
```
